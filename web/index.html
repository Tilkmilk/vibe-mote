诊断
「麦克风自检」读一秒系统默认输入设备并报峰值：读数是 0 就说明「系统这边就没有声音进来」（多半是默认录音设备被设成了 CABLE Output、设备被静音、隐私设置没开、或音频驱动卡死）—— 跟本程序无关。
「按键映射自检」用法：先连按几下遥控器方向键，再点它 —— 日志里会写明钩子读到几次、报文多长、收到几条，用来分清「挂错了宿主」还是「这支遥控器报文格式不同」。公司电脑上按键映射用不了，通常是杀软/EDR 拦了注入：请 IT 把程序目录加进白名单（语音不受影响）。
⚠ 「安装按键映射依赖」会装入 frida，并往系统的蓝牙 HID 驱动宿主里注入一个模块：需要一次管理员权限，可能被杀软误报/隔离，少数带内核反作弊的游戏可能起不来。只要语音就不要装这一项。
遥控器「按键有用、但语音连不上」时用一次：BLE 只接受一个连接，系统有时会把它攥住不放，这一下等于帮你把蓝牙开关关开一次（要一次管理员）。
清理 / 卸载（逐项勾选）
默认什么都不勾，勾哪项删哪项，没勾的一律不动（每一项后面标了"现在在不在／多大"）。 带 🔒 的项需要管理员，会弹一次 UAC。执行顺序固定（先断自启 → 再杀进程 → 再删文件）， 因为不先杀进程就删不掉 .venv（正在运行的 pythonw.exe 被系统锁着； 极端情况下程序会安排到退出后自动删完）。
想彻底卸载整个程序？两步（顺序别反）： ① 这里点「选『推荐清理』」→ 开始清理（清掉开机自启和 frida 残留服务）； ② 然后直接删掉整个程序目录。 程序是纯绿色部署，没有安装器，系统里不会留别的东西 —— 所以内置的 Python 运行时（runtime\）不在清理清单里，它属于程序本体。
